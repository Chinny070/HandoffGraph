# Independent comparison with Ratchet

Ratchet is a separate high-quality GenLayer standalone contract for **irreversible semantic non-weakening of policy tracks**. Its author reports 14 offline + 24 Direct Mode tests and live StudioNet proof, including protected consumer action. Read its actual source and deployment report: <https://github.com/ometere123/ratchet>. We have not independently verified an actual reviewer score breakdown.

HandoffGraph is **not a clone**. It adjudicates acceptance of immutable agent task deliverables, builds a DAG of causally linked dependent tasks, emits final release capabilities, reopens release eligibility upon provenance-bound counterevidence, and repairs history without wiping original decisions. Ratchet neither represents agent task DAGs nor tests artifact completion/release dependencies; HandoffGraph does not compare whether a changed natural-language policy is stricter than an immutable genesis text. The consensus and persistence primitives are broadly shared GenLayer patterns, not copied business functionality.

| Dimension | Ratchet | HandoffGraph v0.3 |
|---|---|---|
| Fundamental decision | Is policy revision strictly stronger? | Does pinned agent work satisfy agreed requirements? |
| Onchain effect | Admit/reject stronger rule revision | Permit/block future dependent agent actions |
| Multi-artifact proofs | Not core focus | Primary plus supplementary SHA-256–pinned material |
| Requirement matrix | Not core focus | Up to six per stage, independent PASS/FAIL/UNKNOWN |
| Causal quarantine | Not core focus | Transitive effective capability revocation after countercase |
| Appeals | Its accepted track is irreversible | Provisional appeal, countercase appeal, bounded repair |
| Optional integrations | Fixed policy version consumer | One-shot action consumer + action-scoped capability consumer |
| Proof available | Documented live StudioNet lifecycle and 24 Direct Mode tests | 133 offline mock tests; no real GenVM or live network proof yet |

A more complex protocol is **not automatically** better. Ratchet currently has stronger real-world deployment evidence. HandoffGraph must reach the same verified standard before anyone claims it scores higher.
